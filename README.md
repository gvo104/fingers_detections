# GestureControl — Система управления компьютером с помощью жестов рук

## Описание проекта

**GestureControl** — это интерактивное приложение, предназначенное для управления компьютером при помощи жестов рук. Система ориентирована на использование в общественных пространствах: выставках, презентациях, интерактивных панелях и других мероприятиях, где требуется бесконтактное взаимодействие с цифровыми интерфейсами.

Проект использует компьютерное зрение и модель машинного обучения для распознавания жестов в реальном времени через веб-камеру. В качестве дополнительной опции предусмотрено определение лица.

## Основные возможности

* Распознавание жестов руки в реальном времени
* Управление действиями на основе распознанных жестов
* Визуальное отображение текущего состояния и распознанного жеста
* Возможность включения/отключения функции распознавания лица
* Использование библиотеки Pillow для высококачественного вывода текста поверх видео


## Использование

Для запуска необходимо подключение веб-камеры. Запустите файл `main.py`:

```
python main.py
```

### Горячие клавиши:

* `Q` — выход из приложения
* `F` — включение/отключение функции обнаружения лица

## Обучающая модель

Для классификации жестов используется модель машинного обучения, сохранённая в файле `train_modul/CSV/model.joblib`. Предполагается, что модель была обучена заранее на основе координат ключевых точек руки (landmarks), извлекаемых с помощью `MediaPipe` или аналогичной технологии.

## Области применения

* Интерактивные выставочные и рекламные стенды
* Образовательные демонстрации
* Информационные панели в общественных местах
* Киоски бесконтактного взаимодействия
